## Information and coordination

- Hiding fields in a prompt is insufficient if the context still contains private inventories/consent, or the executor tracks remote citizens' live positions. Enforce the boundary in both context and execution.
- A location report is a snapshot, not a tracking subscription or a disclosure of hunger, inventory, or consent. Local sightings can update it; remote state changes cannot.
- Messages can express intentions, but do not grant mechanical consent or guarantee resources. Private reports must reach only their recipient. A stale in-flight model response must not erase a later message's next-review trigger.
- Nearby dependent care is an explicit deterministic family policy, not permission to inspect distant family members' private needs.
- Spectator inspection is not citizen knowledge. Label full-world views; citizen maps must use remembered sightings/reports, including remembered people.
