## Research directions

[Generative Agents](https://arxiv.org/abs/2304.03442) combines observation, memory retrieval, reflection and planning to produce social behavior. The useful direction here is selective memory and outcome-based revision, rather than copying a growing transcript or prescribed town story.

[SayCan](https://arxiv.org/abs/2204.01691) grounds high-level choices in executable skills and contextual feasibility. Prosper should provide useful action affordances and prerequisites while deterministic execution handles geometry. We do not have trained skill value functions, so heuristic costs must be identified as estimates.

[Behavior Trees Enable Structured Programming of Language Model Agents](https://arxiv.org/abs/2404.07439) describes combining language reasoning with reactive conventional control. Existing needs/task/work execution already provides much of that separation; evaluate missing reactions rather than adding an arbitrary new planning language.

[DEPS](https://arxiv.org/abs/2302.01560) uses execution feedback and correction, with a selector considering subgoal difficulty. Applying that principle here means exposing stalled progress, real costs and actionable errors; it does not justify fixed goals or mandatory social behavior.
