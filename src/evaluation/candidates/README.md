# Primitive candidates, first slice

Exports are in `src/evaluation/candidates/index.ts`.

- `createNoCommandCandidate()` is a fresh advance-only baseline. It never dispatches or inserts a command.
- `decodePrimitiveDecision(value, { requestId, maxOutputBytes, allowedCommands? })` accepts one strict real-command envelope or advance envelope. It rejects aliases, prose, markdown, extra fields, duplicate JSON keys, stale IDs and byte overflow. It neither repairs nor tests knowledge/affordability; the runner owns the known-command gate and execution.
- `createLocalModelCandidate(config, transport)` accepts injected **mock** transport or the actual audited `OllamaTransport` class. Configuration requires explicit loopback endpoint/model and prompt/input/output bounds. Arbitrary `local` capability metadata still fails admission. No cloud fallback, retry, query, macro or prerequisite selection is supplied. The local path requires a task-owned process controller, exact installed Qwen GGUF/digest/size verification, conservative byte-based input/context bounds, bounded HTTP output, receipts and explicit positive runner budgets. See `docs/research/evaluation-harness-usage.md` for its separate opt-in resource gate.
- `MECHANICS_CONTEXT` aliases the runner's single frozen source-derived public manual. It is not a fixture manual or strategy. The prompt and configuration are hashed in candidate metadata.

The runner supplies only citizen observations, public mechanics/objectives and limits. Every factory has private episode state; reset clears history, requests, usage and seed. Seeds are uint32 and are candidate seeds, not world seeds. No learned state, skills or cross-episode memory is retained.

History is FIFO with separately configured entry and UTF-8 byte limits (default 4 entries/32,000 bytes). Oversized feedback is omitted rather than rewritten, with omission counts included in the next prompt. Full current observations are not silently pruned: messages plus schema exceeding `maxPromptBytes` fail before transport invocation. Scratch/serialized byte bounds do not establish OS/process memory containment; only cooperative audited in-process candidates are supported.

## Accounting and cancellation

`getUsage()` returns cumulative decisions, output UTF-8 bytes, settled wall time, history usage and omissions. Model candidates additionally expose `modelCalls`, `tokens`, `reservedTokens`, reported input/output totals, unknown-receipt call count, messages-plus-schema bytes and transport status. Injected mock usage is **mock diagnostics**, not provider token evidence. Audited local usage includes actual Ollama token receipts after a settled generation; missing/failed/aborted receipts remain conservative reservations. Pre-generation verification failures may consume a reserved adapter attempt without any generation, so attempted calls must not be described as successful inference. The runner can enforce numeric episode ceilings and optional per-decision ceilings through the shared usage API.

Before each single transport attempt, the adapter reserves `maxInputTokens + maxOutputTokens`. A valid receipt can reduce charged tokens to reported usage; missing, malformed, failed, aborted and late receipts keep the full bound. A transport must actually enforce the requested token/output caps before these reservations can represent a real provider bound. The cooperative protocol alone cannot prove that. No unknown usage is recorded as zero. An unavailable episode call/token reservation throws the shared `CandidateBudgetFailure` with scope `episode`; the runner must stop incomplete before cadence, not turn exhausted resources into free advances. Per-decision cap refusal remains an ordinary contained failure.

`getLastResponse()` is audit-only. It returns a detached current response snapshot captured before decoding or token-receipt validation: exact text within `maxOutputBytes`, otherwise only UTF-8 byte count and SHA-256. Reset, each new decision attempt and close clear it; late aborted output cannot repopulate it. The runner may retain this in privileged trace, never candidate feedback or prompts.

The per-decision signal combines caller abort, episode close and timeout. Ignoring abort rejects the decision promptly, but blocks new decisions/reset until the original transport settles. Generation checks suppress late decisions. `pendingOperations` remains 1 while a transport is unsettled, even after the decide hook rejects; the runner must treat that boundary as unsafe and stop before cadence. Close clears private episode memory and invalidates responses. For the audited local transport it also awaits observed task-owned service shutdown; failed shutdown remains pending indefinitely, so the runner's teardown deadline stops incomplete rather than claiming successful cancellation. Arbitrary uncooperative mock transport still has no claimed underlying teardown. Episode wall time and teardown admission remain runner responsibilities.

## Offline/mock coverage

`test/evaluation-candidates.test.ts` covers all 19 current command variants, strict malformed/ambiguous JSON and bounds, public subset restrictions, semantic-gate separation, no-command behavior, lifecycle/isolation/seed checks, public prompt inputs, explicit local configuration, reservations/receipts, prompt/output limits, bounded feedback history, timeout/close/ignored-abort containment. It imports no evaluator fixtures/reference trajectories and performs no model inference. `test/evaluation-transport.test.ts` verifies real HTTP protocol shapes against mocked responses and process-stop callbacks; `test/evaluation-live.test.ts` verifies audited-class runner admission, real-engine commit/replay and pending-stop containment using mock HTTP only. Neither starts inference. This is protocol evidence, not model decision-quality or general-search evidence.
